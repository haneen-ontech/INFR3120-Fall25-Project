# INFR3120 – Project Part 3

## Project Overview
This first release is the initial version of our group web application for **INFR3120 – Web & Scripting Programming**.  
The goal for Part 1 was to set up the basic site structure, build the main pages, implement CRUD functionality, collaborate via GitHub, and deploy the project online.

## Project Layout
Our project is a multi-page website built using **HTML**, **CSS**, **Bootstrap**, and **FontAwesome**.  
It currently includes four main pages:

- **Home** – Landing page with the site logo, title, and main hero button  
- **About Us** – A short overview of the team and project  
- **Contact Us** – A working contact form  
- **Records** – Page with full CRUD functionality  
- **Authentication** – Login & Register pages.

## Features Implemented

### Landing Page
- Shows the project name and a custom logo  
- Includes a hero button that links to the object creation page  
- Styled using Bootstrap
- Same header/footer layout across all pages

### Navigation
- Responsive Bootstrap navbar  
- FontAwesome icons included  

### Authentication
Users can:
- **Register**
- **Login**
- **Perform CRUD operations**

### CRUD Functionality (Records Page)
Users can:
- **Create** records  
- **View** all records in a table  
- **Update** existing records  
- **Delete** records

### Completed Pages
- Home  
- About Us  
- Contact Us  
- Records

All pages consist of a bootstrap responsive layout
